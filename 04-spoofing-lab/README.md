# Spoofing (Lab Only)

Active man-in-the-middle demonstrations: ARP cache poisoning and DNS response
spoofing. These scripts alter traffic on the local network. Run them only
inside an isolated lab you control, with forwarding configured as documented
in each script.

| Script | Purpose |
| --- | --- |
| `arp_spoof.py` | Demonstrate ARP spoofing and packet forwarding concepts. |
| `dns_spoof.py` | Watch DNS requests and send spoofed DNS responses. |
