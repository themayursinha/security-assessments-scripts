# Server & Client Examples

Minimal TCP/HTTP servers and clients. Useful for learning socket programming
and as throwaway listeners during lab work (payload delivery, callback
testing).

| Script | Purpose |
| --- | --- |
| `BaseHTTPServer1.py` | Minimal custom HTTP server example. |
| `SimpleHTTPServer1.py` | Static HTTP server with a custom /test route. |
| `tcpClient_signals.py` | Basic TCP client with SIGINT cleanup. |
| `tcpServer_SocketServer.py` | Basic TCP echo server using socketserver. |
| `tcpServer_signals.py` | TCP listener example with signal handling. |
| `ftp_explorer.py` | Connect to FTP servers from a list and list directories. |
