# Encoding & Hash Utilities

Small data-transformation tools used constantly during assessments: Base64,
XOR, and common hash calculations. Safe to run on any input.

| Script | Purpose |
| --- | --- |
| `basic_hash_tool.py` | Calculate common hashes for files or strings. |
| `ez_base64.py` | Encode or decode a value with Base64. |
| `xor_file.py` | XOR an input file with supplied hex bytes. |
