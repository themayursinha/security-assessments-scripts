# Python Fundamentals

Language-learning examples that security tooling builds on: exceptions,
signals, forking, threads, queues, locks, debugging, and a database client.
Read these before diving into the assessment categories.

| Script | Purpose |
| --- | --- |
| `forker.py` | Demonstrate process forking. |
| `lock_threads.py` | Thread locking around a shared counter. |
| `mysql_example.py` | Minimal MySQL usage example. |
| `pdb_example.py` | Small debugger example. |
| `pythagoras.py` | Input handling, type conversion, basic math. |
| `signals.py` | Custom signal handling. |
| `threads1.py` | Basic worker-thread queue example. |
| `threads2.py` | Thread queue example with command-line options. |
| `user_exceptions.py` | Custom exception classes. |
